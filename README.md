# Quiz Engine – Python & MySQL

A console-based Quiz Engine built using **Python and MySQL**.  
The application allows users to register, log in, view available quizzes, answer multiple-choice questions, calculate scores, and view their completed quiz results.

## 🚀 Features

- User Registration
- User Login Authentication
- View Available Quizzes
- Take Multiple-Choice Quizzes
- Instant Correct/Wrong Answer Feedback
- Automatic Score Calculation
- Quiz Attempt Tracking
- Store User Answers in MySQL
- View Completed Quiz Results
- Input Validation
- Database Error Handling
- MySQL Database Integration

## 🛠️ Technologies Used

- **Python 3**
- **MySQL**
- **mysql-connector-python**

## 📚 Python Concepts Used

- Functions
- Conditional Statements
- Loops
- Lists
- Tuples
- Exception Handling
- String Handling
- User Input
- MySQL CRUD Operations
- Parameterized SQL Queries
- Database Connectivity
